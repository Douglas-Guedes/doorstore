# \# DoorStore

# 

# Vitrine de chaves de jogos digitais para PC com foco em promoções.

# A página única apresenta uma listagem principal de jogos em promoção,

# com gênero, preço original, percentual de desconto, preço final e nota,

# e uma listagem secundária com os próximos lançamentos e suas datas.

# O projeto é um trabalho acadêmico, sem login, pagamento ou carrinho real,

# e será desenvolvido com React, TypeScript e Tailwind CSS.
